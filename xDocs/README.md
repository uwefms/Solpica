## FileServer
		
A simple file server that serves files from the resources files folder. 
It can be run locally or on a web server. It is used to serve the files for the API test program. The fileServer.http
file demonstrates the access to the different functions. 

For using the web server option, create a file called WebSrv.txt containing the address of the web server 
(like https://abc.de/Fileserver)and put it in c:\dev\
